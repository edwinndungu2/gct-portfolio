HOW TO OPEN
1. Extract the ZIP file.
2. Keep the index.html, styles.css, script.js and assets folder together.
3. Open index.html in a browser, or upload the complete folder contents to your web host.

CUSTOMISATION
- Update business copy and contact details in index.html.
- Change colours, spacing and layout in styles.css.
- Google Fonts and solution photography load from external services when an internet connection is available; system font fallbacks are included.
- Solution photography uses lazy-loaded images with descriptive alternative text. Replace the image URLs and alt text in index.html with approved GridHub project photos when available.
- Each solution card links to a standalone detail page in products/; product descriptions avoid listing unconfirmed brands, prices or guaranteed capabilities.
- The site includes a keyboard-accessible skip link, responsive sticky navigation and a floating WhatsApp shortcut outside the contact section.
- The enquiry form prepares a message in WhatsApp; visitors review and send the message themselves. Enquiry details are not stored by this static site.
- The website is a static front-end portfolio. It does not include online payments, customer accounts or a booking backend.

The site intentionally avoids claiming certifications, awards, client numbers or guarantees that have not been provided.
